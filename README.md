# 백색 서고

기사·궁수·마법사 중 한 직업으로 서고를 탐험하는 한국어 텍스트 RPG입니다. 단어를 모아 공격을 조합하고, 전투·휴식·층별 적과 보스를 거치며 이 브라우저의 세 슬롯에 여정을 저장합니다.

## 실행

Node.js 22.12 이상과 npm이 필요합니다. 로컬 검증 환경은 Node.js 22.23.4와 npm 11.19.0입니다.

```sh
npm ci --ignore-scripts
npm run dev
```

production build 확인:

```sh
npm run check
npm run preview
```

표시된 loopback 주소를 엽니다. `dist/`는 정적 호스팅할 수 있으며 계정·서버 API·환경 파일이 필요하지 않습니다. 폰트·사진·음원을 외부에서 불러오지 않습니다.

## 플레이

새로운 여정에서 직업을 고르고 탐색합니다. 형용사를 수집하면 단어 공격을 사용할 수 있습니다. 보유한 첫 형용사와 첫 동사를 자동 조합하며 동사가 없으면 기본 베기를 사용합니다. 단어의 힘을 피해량에 반영합니다. 직업별 필살기, 방어와 포션을 사용할 수 있습니다. 층마다 열 번의 사건을 진행합니다. 마지막 사건에는 중간보스가, 다섯 층마다 보스가 등장합니다.

전투 중에도 저장하거나 타이틀로 돌아갈 수 있습니다. 적의 차례에 저장한 슬롯을 다시 열면 해당 여정의 적 차례를 이어갑니다. 다른 슬롯·새 여정·타이틀로 전환하면 이전 전투의 예약 동작을 취소합니다.

## 저장과 복구

`white-library-save-1`부터 `white-library-save-3`까지 현재 origin의 localStorage를 사용합니다. 탐색·전투·포션 사용과 타이틀 이동 시 저장하고 수동 저장도 제공합니다. 계정 저장·기기 간 동기화·파일 import/export는 없습니다.

손상·미지원·읽기 거부를 빈 슬롯으로 취급하지 않습니다. 읽을 수 없는 원문을 자동 덮어쓰거나 삭제하지 않고 상태를 표시합니다. 저장소를 사용할 수 없으면 경고와 함께 현재 화면에서만 진행할 수 있습니다. 읽지 못한 슬롯에서 저장 없이 시작한 여정은 접근이 회복돼도 해당 슬롯을 덮어쓰지 않습니다. 타이틀에서 저장을 다시 읽고 이어하기 또는 새 여정을 명시적으로 선택해야 저장 세션을 시작합니다. `이어하기`의 기록 지우기는 확인 후 해당 슬롯만 지우며, 읽은 뒤 바뀐 기록은 삭제하지 않습니다. 새로고침이나 브라우저 데이터 삭제 전에 저장 상태를 확인하세요.
